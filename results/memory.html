🧠 Handshake Memory Consumption (RAM)

Memory consumption (RSS) of OpenSSL s_server during TLS handshakes. This measures the Resident Set Size (physical RAM used) during connection establishment for different OpenSSL versions. Lower is better.

Why This Matters: Memory consumption differences between 1.1.1w and 3.x versions were raised as a concern. This data shows actual RAM impact during TLS 1.2 and TLS 1.3 handshakes.
