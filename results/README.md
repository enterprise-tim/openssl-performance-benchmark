# OpenSSL Benchmark Visualization Results

## Overview

This directory contains the visualization outputs for the OpenSSL performance benchmark suite.

## Files

### Main Visualizations

- **`visualizations.html`** - Complete interactive dashboard with all benchmark results
  - Multiple tabs covering different aspects of OpenSSL performance
  - Tab 2 features the new **Slope Chart** for TLS 1.2 vs 1.3 comparison
  - Requires `summary.json` with benchmark data

### Demos & Examples

- **`tls-comparison-demo.html`** - Standalone demo of the TLS slope chart
  - Uses sample data to showcase the visualization
  - No benchmark data required
  - Perfect for understanding the visualization concept

- **`comparison-before-after.html`** - Side-by-side comparison showing the improvement
  - Left: Traditional grouped bar chart
  - Right: New interactive slope chart
  - Includes pros/cons analysis

### Data Files

- **`summary.json`** - Aggregated benchmark results (generated by running benchmarks)

## TLS 1.2 vs 1.3 Visualization

### What Makes It Compelling?

The new **slope chart** (also called a slopegraph) replaces the basic bar chart with an interactive visualization that:

1. **Shows relationships immediately** - Lines connect TLS 1.2 to TLS 1.3 performance
2. **Visual storytelling** - Upward slopes = TLS 1.3 faster, downward = TLS 1.2 faster
3. **More information** - Displays percentage changes explicitly
4. **Interactive** - Hover over lines for detailed tooltips
5. **Professional design** - Modern, engaging visualization

### Key Features

- **Color-coded lines** - Each OpenSSL version has its own color
- **Percentage labels** - Green for improvements, red for regressions
- **Version labels** - Easy identification on the left side
- **Interactive tooltips** - Detailed information on hover
- **Grid lines** - For precise value reading

### D3.js Capabilities Used

- Scale functions (`d3.scaleLinear`, `d3.scalePoint`)
- Interactive elements (hover effects, tooltips)
- SVG line drawing and styling
- Force simulation for label positioning (in main viz)
- Color scales and data binding

## Viewing the Visualizations

### Option 1: Open in Browser
Simply open any `.html` file in a web browser:
```bash
open results/tls-comparison-demo.html
# or
open results/comparison-before-after.html
```

### Option 2: View Main Dashboard
After running benchmarks:
```bash
npm run visualize
open results/visualizations.html
```

## Technical Details

### Data Requirements

For the TLS comparison to work, the benchmark data needs:
- `tls1_2_ecdhe_rsa_aes128gcm_cps` - TLS 1.2 connections per second
- `tls1_3_rsa_new_cps` - TLS 1.3 connections per second

If these metrics aren't available, the visualization displays a helpful message explaining what's needed.

### Browser Compatibility

All visualizations work in modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- No IE support (uses modern JavaScript and D3.js v7)

## Why This Approach?

### Traditional Bar Chart Problems
- ❌ Requires mental comparison of bar heights
- ❌ Difficult to see relationships between protocols
- ❌ No indication of improvement vs regression
- ❌ Less engaging visually
- ❌ Doesn't leverage D3.js capabilities

### Slope Chart Advantages
- ✅ **Immediate insight:** Slope direction shows winner
- ✅ **Visual storytelling:** Lines tell a clear story
- ✅ **Interactive:** Hover for detailed information
- ✅ **More information:** Shows % change explicitly
- ✅ **Pattern recognition:** Easy to spot outliers
- ✅ **Professional:** Modern, compelling design
